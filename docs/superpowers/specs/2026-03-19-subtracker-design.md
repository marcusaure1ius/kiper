# SubTracker — Android-приложение для учёта подписок

## Обзор

Мобильное приложение на Flutter для учёта всех регулярных подписок и платежей. Позволяет видеть полную картину расходов, получать напоминания о списаниях, анализировать траты по месяцам и категориям, прогнозировать будущие расходы.

## Ключевые возможности

- Каталог всех регулярных подписок (цифровые сервисы + регулярные платежи)
- Каталог популярных сервисов с иконками для быстрого добавления
- Категории подписок (развлечения, связь, AI-сервисы и т.д.)
- Гибкие периоды списания (неделя, месяц, квартал, полгода, год, произвольный)
- Мультивалютность (RUB/USD/EUR) с автопересчётом в рубли по курсу ЦБ РФ
- Графики расходов по месяцам (прошлое) + прогноз списаний (будущее)
- Напоминания перед списанием (локальные уведомления)
- Экспорт/импорт данных (JSON/CSV)
- Material You (Material 3), тёмная/светлая тема, Dynamic Color

## Модель данных

### Subscription

| Поле | Тип | Описание |
|------|-----|----------|
| id | UUID | Уникальный идентификатор |
| name | String | Название (Netflix, МТС...) |
| icon | String? | Путь к иконке (из каталога или null) |
| amount | double | Сумма списания |
| currency | enum (RUB, USD, EUR) | Валюта |
| billingPeriod | enum (weekly, monthly, quarterly, semiannual, annual, custom) | Период |
| customPeriodDays | int? | Дней в периоде (если custom) |
| categoryId | UUID? | Ссылка на категорию (null = «Другое») |
| nextBillingDate | DateTime | Дата следующего списания |
| reminderDaysBefore | int | За сколько дней напоминать (по умолчанию 1) |
| status | enum (active, paused, cancelled) | Состояние подписки |
| startDate | DateTime | Дата начала подписки (для исторической аналитики) |
| note | String? | Заметка |
| createdAt | DateTime | Дата создания записи |

**Статусы подписки:**
- `active` — активна, генерирует прогноз и уведомления
- `paused` — временно приостановлена (без прогноза и уведомлений, остаётся в списке серой)
- `cancelled` — отменена, скрыта из основного списка, но сохраняется для аналитики

### Category

| Поле | Тип | Описание |
|------|-----|----------|
| id | UUID | Уникальный идентификатор |
| name | String | Название (Развлечения, Работа...) |
| color | int | Цвет для графиков и UI |
| icon | String | Иконка категории (Material Icon) |

### ExchangeRate

| Поле | Тип | Описание |
|------|-----|----------|
| from | enum | Исходная валюта |
| to | enum | Целевая валюта |
| rate | double | Курс |
| updatedAt | DateTime | Когда обновлён |

Курсы обновляются при открытии приложения через API ЦБ РФ (`https://www.cbr.ru/scripts/XML_daily.asp`), кэшируются локально. Без интернета используется последний сохранённый курс. При первом запуске без интернета — захардкоженные fallback-курсы с пометкой «курс приблизительный».

**Предустановленные категории (seed при первом запуске):**
- Стриминг (фиолетовый)
- AI-сервисы (синий)
- Связь (оранжевый)
- Развлечения (красный)
- Другое (серый)

## Навигация

Bottom Navigation Bar с 3 табами:

| Таб | Экран | Описание |
|-----|-------|----------|
| Подписки | Главный список | Все активные подписки, сумма в месяц сверху, FAB для добавления |
| Аналитика | Графики | Столбчатый график по месяцам, прогноз, круговая диаграмма по категориям |
| Настройки | Настройки | Тема, категории, экспорт/импорт, уведомления |

### Ключевые экраны

1. **Список подписок** — карточки (Material 3 Card) с иконкой, названием, суммой, датой следующего списания. Фильтр по категориям. Общая сумма в месяц (в рублях) в шапке.
2. **Добавление/редактирование** — форма с полями из модели. Вверху — выбор из каталога популярных сервисов или ручной ввод.
3. **Детали подписки** — просмотр, редактирование, удаление.
4. **Аналитика** — столбчатый график (прошлые месяцы — сплошные, прогноз — пунктирные) + круговая диаграмма по категориям.
5. **Настройки** — переключение темы, управление категориями, экспорт/импорт, настройки уведомлений.

## Каталог популярных сервисов

Встроенный каталог для быстрого добавления. При выборе заполняются: название, иконка, валюта, типичный период. Пользователь вводит только сумму и дату.

| Категория | Сервисы |
|-----------|---------|
| Стриминг | Netflix, YouTube Premium, Spotify, Apple Music, Яндекс Музыка, Кинопоиск |
| AI-сервисы | Claude, ChatGPT, Perplexity, Google AI (Gemini) |
| Связь | МТС, Билайн, Мегафон, Tele2, Ростелеком |
| Развлечения | PlayStation Plus, Xbox Game Pass, Steam |

Хранение: JSON в assets + SVG-иконки. Каталог работает офлайн. Пользователь может изменить любое предзаполненное поле.

## Уведомления и напоминания

- Локальные уведомления через `flutter_local_notifications` (scheduled notifications)
- При добавлении подписки планируется уведомление на `nextBillingDate - reminderDaysBefore`
- Продвижение `nextBillingDate`: при открытии приложения проверяются все подписки — если `nextBillingDate` в прошлом, дата сдвигается вперёд на нужное количество периодов до ближайшей будущей даты, планируется новое уведомление

**Настройки на уровне подписки:**
- За сколько дней напоминать: 1 / 3 / 7 дней (по умолчанию — 1)
- Можно отключить для конкретной подписки

**Содержание уведомления:**
- Заголовок: название сервиса
- Тело: «Списание ₽2,115 (~$22.99) завтра»
- Тап открывает детали подписки

**Глобальные настройки:**
- Время отправки (по умолчанию 10:00)
- Глобальное вкл/выкл всех напоминаний

## Экспорт/Импорт

**Форматы:**
- **JSON** — полный бэкап (подписки, категории, настройки)
- **CSV** — плоская таблица подписок для Excel/Google Sheets

**Экспорт:** кнопка в настройках → выбор формата → системный share sheet.
Имя файла: `subtracker-backup-2026-03-19.json`

**Импорт:** кнопка в настройках → file picker.
- JSON: «Заменить все данные или объединить?» При объединении — сопоставление по UUID, конфликты (одинаковый UUID, разные данные) решаются в пользу импортируемого файла. Неизвестная версия формата — показать ошибку «обновите приложение».
- CSV: добавление подписок, категории сопоставляются по имени. Если категория не найдена — создаётся новая.

**Структура JSON-бэкапа:**
```json
{
  "version": 1,
  "exportedAt": "2026-03-19T10:00:00Z",
  "subscriptions": [],
  "categories": [],
  "settings": {}
}
```

Поле `version` для обратной совместимости.

## Логика прогноза

- Берём все подписки со статусом `active`
- Для каждой вычисляем будущие даты списания на 6 месяцев вперёд на основе `billingPeriod` и `nextBillingDate`
- Суммы конвертируем в рубли по текущему курсу ЦБ
- Отображаем как пунктирные столбцы на графике аналитики

**Историческая аналитика:**
- Прошлые расходы реконструируются по `startDate`, `billingPeriod` и `amount` — отматываем периоды назад от `nextBillingDate` до `startDate`
- Это приблизительные данные (не учитывает изменения цены в прошлом), но достаточно для общей картины

## Удаление подписки

- Удаление через экран деталей с диалогом подтверждения
- Мягкое удаление: подписка получает статус `cancelled`, исключается из списка и прогноза, но остаётся в БД для исторической аналитики
- Запланированные уведомления отменяются при удалении
