# Кипер для iOS

Нативное приложение на SwiftUI для iOS 26 с Liquid Glass. Повторяет возможности Android-версии (`../lib`) и совместимо с ней по резервным копиям.

## Сборка и запуск

Нужен Xcode 26+. Внешних зависимостей нет.

```bash
open Kiper.xcodeproj                      # схема Kiper, симулятор iPhone 17 Pro
```

Из терминала:

```bash
xcodebuild -project Kiper.xcodeproj -scheme Kiper \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build
xcodebuild -project Kiper.xcodeproj -scheme Kiper \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' test
```

Проект использует папки, синхронизируемые с Xcode: новые файлы в `Kiper/` и `KiperTests/` подхватываются без правки `project.pbxproj`.

## Устройство

| Папка | Что внутри |
|---|---|
| `Kiper/App` | Точка входа, таб-бар, `AppDelegate` (уведомления, переход по нажатию) |
| `Kiper/Data` | `AppStore` (состояние и расчёты), хранилище, бэкап и CSV, курсы ЦБ, напоминания, сид |
| `Kiper/Models` | `Subscription`, `Category`, `Currency`, `BillingPeriod`, `SubscriptionStatus` |
| `Kiper/Features` | Экраны: Главная, Подписки, Аналитика, Настройки |
| `Kiper/Shared` | Фон и палитры, анимации, компоненты, форматирование, навигация |
| `KiperTests` | Unit-тесты (Swift Testing) |
| `KiperUITests` | Сквозной тест: настоящее напоминание → нажатие на баннер → открывается подписка |

### Данные
- Всё хранится в одном JSON-файле `Application Support/kiper.json` в **формате бэкапа Android-версии** (`BackupData` v1). Запись атомарная, при каждом изменении.
- Первый запуск: создаются 5 категорий. Тестовые подписки добавляются только в DEBUG-сборке, как в Android.
- Если файл не читается, он не перезаписывается. В Настройках появляется предупреждение и предложение восстановить данные из копии.
- Прошедшие даты списаний активных подписок сдвигаются вперёд при запуске и при возврате в приложение.
- Отмена подписки — мягкое удаление: статус меняется на `cancelled`, а запись остаётся для аналитики. При удалении категории у подписок обнуляется `categoryId`.

### Автокопия
Настройки → Резервная копия: пользователь один раз выбирает папку в «Файлах» (например iCloud Drive → Кипер). Доступ сохраняется security-scoped bookmark — iCloud-entitlement и платный аккаунт не нужны. После каждого изменения (с задержкой 2 с) и не реже раза в день пишется «Кипер — копия.json» и датированная копия; хранятся копии за 7 дней.

### Курсы валют
`https://www.cbr.ru/scripts/XML_daily.asp` (windows-1251, десятичная запятая, учитывается `Nominal`). Курсы кэшируются в `UserDefaults` и обновляются не чаще раза в 6 часов, плюс кнопка в Настройках. Без сети используется кэш, а если его нет — резервные курсы (USD 90, EUR 98).

### Напоминания
Локальные уведомления в выбранное время за `reminderDaysBefore` дней до списания. Текст такой же, как в Android. На каждую активную подписку ставится одно уведомление, всего не больше 60 (у iOS лимит 64). При любом изменении данных набор пересоздаётся. Нажатие на уведомление открывает подписку.

### Экспорт и импорт
- **JSON:** подписки и категории. Иконки Material и SF Symbols переводятся друг в друга, цвет хранится как ARGB-число, даты — в формате `DateTime.parse` из Dart.
- **CSV:** только подписки, те же колонки, что в Android.
- **Импорт** через «Файлы»: можно заменить все данные или объединить их с текущими (upsert по `id`).

## Установка на свой iPhone без платного аккаунта

Бесплатная подпись живёт 7 дней. Скрипт переустанавливает приложение (данные сохраняются), когда телефон доступен по кабелю или в той же Wi‑Fi и разблокирован:

```bash
./scripts/install-schedule.sh              # launchd: 10:00, 15:00, 21:00 и при входе; реальная переустановка — раз в 3+ дня
./scripts/refresh-device.sh --force        # переустановить прямо сейчас
./scripts/install-schedule.sh --uninstall  # убрать расписание
```

Лог: `~/Library/Logs/kiper-refresh.log`. UDID телефона задаётся `KIPER_DEVICE_ID`.
